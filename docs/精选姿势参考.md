# 精选姿势参考@泡老师的小课堂

节点分类：`🍭大炮-llama-cpp`；内部类型：`DapaoPoseReference`。

## 使用

1. 启动或重启本套 ComfyUI 后刷新网页，双击画布搜索“精选姿势参考”。
2. 点击“🧍打开精选姿势库”，选择体系、动作分类，或搜索名称、编号、ID。
3. 点击卡片，右侧切换正面、斜侧、侧面、俯视、仰视；点击“使用此视角”。
4. 把“🖼️姿势参考图”连接到预览图像、保存图像或需要 IMAGE 的下游节点。运行工作流时读取本地图片。

另有“📝姿势说明”和“🆔姿势ID”字符串输出。选择保存在节点的“🧍姿势ID”字段，随 ComfyUI 工作流序列化；素材须与插件一起保留。空 ID 不会偷偷选择第一张，运行时会明确提示先选择。

## 图库功能

- 4 个体系、动作分类、名称/编号/ID/关键词组合搜索、视角多选及重置。
- 按姿势分组、逐张浏览；每次显示 30 张卡片，按需加载更多，图片懒加载。
- 卡片视角悬停预览，详情保留同一姿势全部实际视角，缺失角度禁用并标注。
- 姿势说明、视角、规格、ID；上一/下一姿势；大图缩放与视角导航。
- 下载 WebP、复制 ID、新窗口、浏览器原生图片右键保存/复制。
- 左右方向键切换视角，上下切换姿势，`/` 搜索，`Esc` 关闭；详情图支持触屏左右滑动。
- 桌面双栏、窄屏双列卡片及纵向详情；加载、空结果、失败重试、禁用与选中状态。
- 确认前解码检查，取消、读取失败和节点被删除时不会将新选择写回；关闭子窗口清理。
- 使用指南、作者署名及来源声明。全部素材在本地，无生成 API、模型加载或自动下载。

## 素材与压缩

从用户指定的本地项目复制其已经压缩的资源，保留原始清单与哈希：288 组 / 1439 张，600×800、WebP、quality 40，图片共 **18.05 MiB**，加清单与声明约 **18.45 MiB**。没有对已压缩图片再次有损转码；不需要在线原图。所有路径锚定插件目录，无硬编码盘符。

来源：[中文仓库](https://github.com/anhao/ai-pose-gallery-zh)、[中文网页](https://ai-pose-gallery.anhao.app/)。图片/原始数据作者ギア，中文整理 Anhao。素材不适用代码 MIT 许可；来源声明禁止商业用途，不能将本次本地接入视为商业分发授权。完整声明见 `resources/pose-gallery/SOURCE-LICENSE.txt`。
