# 精选服装参考@泡老师的小课堂

分类：`🍭大炮-llama-cpp`；内部节点类型：`DapaoCostumeReference`。

## 使用

1. 首次安装本节点后，启动或重启这套 ComfyUI，再刷新网页。
2. 双击画布，搜索“精选服装参考”。节点内六宫格可直接选常用服装，选中项有蓝框与勾。
3. 点击“打开完整服装库”，按八个分类筛选，或搜索编号、中文标签、英文关键词。多个词以空格分隔，表示同时匹配。
4. 点击服装查看详情。列表使用缩略图，详情与放大窗口使用原尺寸无损图；可放大到 1:1 检查衣料细节。
5. 选择中文或 English，点击“使用这套服装”。语言和素材 ID 随工作流保存。关闭弹窗不应用其中的选择或语言变化。
6. 把图片输出连到“预览图像”或其他 IMAGE 输入。示例工作流在 `example_workflows/精选服装参考_预览.json`，只读取本地图片，不生成图片。

| 输出 | 内容 |
|---|---|
| 🖼️服装参考图 | 原尺寸 RGB IMAGE，float32、0–1；不会将缩略图作为最终输出 |
| 📝服装说明 | 素材 ID、分类与中文标签 |
| ✨服装提示词 | 当前所选语言的正向提示词 |
| 🚫反向提示词 | 当前所选语言的反向提示词 |
| 🆔服装ID | 稳定素材编号 |

点击节点内语言按钮立即修改该节点输出语言；完整图库中的语言按钮在确认使用后才写回。图片加载失败保留旧选择，原图缺失不会退回低清缩略图。空 ID 执行时明确提示先选图。

## 界面与交互

- 沿用姿势节点的六宫格、蓝色主按钮、紧凑外框和内部滚动布局；同一个 DOM 面板承载全部控件。
- 快捷区选择春、夏、秋、冬、派对、泳装的实际素材；从完整图库选择其他服装后，会在第一格显示当前选择。
- 8 分类、组合搜索、每批 30 张、图片懒加载、原尺寸大图与缩放、1:1、无损图片下载、正反向提示词及 ID 复制。
- 左右方向键或详情图左右滑动切换当前筛选范围内的服装，`/` 搜索，`Esc` 关闭弹窗。
- 目录/图片加载失败可重试；节点删除或参数改变后，迟到结果不覆盖现有选择。
- 本库每套只有一张图，不提供不存在的多视角切换。

## 本地素材与分发边界

素材通过插件目录相对位置读取：

```text
resources/costume-gallery/
  manifest.json
  SOURCE-LICENSE.txt
  image/<素材ID>.webp     原尺寸无损图
  thumb/<素材ID>.webp     360×540 缩略图
```

当前本机已配置 1407 套、8 分类，总体积约 **916.47 MiB**；其中无损图约 **904.10 MiB**。没有复制原图库的有损 display 图片，运行不依赖桌面目录或压缩实验目录。原桌面素材完整保留。

无损图来自已完成逐像素一致性验证的压缩版本，尺寸保持原样；多数为 1366×2048，部分素材尺寸不同。迁移后再次校验全部无损图 SHA-256、大小、解码尺寸，以及全部缩略图解码。

来源为素材自带说明列出的 [AI 服装素材库](https://ai-costume-gallery.pages.dev/)。素材说明允许创作参考，但禁止图片原件及加工版本再次分发。该目录及压缩实验素材已添加 Git 忽略，**不会随公开节点代码发布**；这不能替代发行时对其他打包方式的检查。不要把本地素材目录随公开压缩包分发。

换电脑时，此节点不会自动联网下载素材。缺少目录会显示配置提示，其他节点仍正常注册。提示词与中文标签是离线库根据公开关键词整理的文本，不是原作者的原始生成提示词；服装是 AI 生成的虚构设计。
