# 美女脸模素材@泡老师的小课堂

分类：`🍭大炮-llama-cpp`；节点类型：`DapaoFaceReference`。

## 使用

首次安装新节点后，启动/重启 ComfyUI 并刷新网页，搜索“美女脸模素材”。节点中的六宫格可快速选择四种发型的脸部参考与两张造型参考；“打开完整脸模库”进入完整图库。

- 素材类型：脸部参考 893 张、造型参考 606 张。
- 发型：短发 727、中发 376、半长发 260、长发 136。
- 可按具体发型描述筛选（原库 50 种非空描述），搜索编号、中英文标签或造型描述；空格分隔多个关键词表示同时匹配。
- 可按原库顺序、下载总排行、发型内排行排序。原库未提供排行的条目排在有排行条目后面；排行是离线库中的快照，不是实时网络排行。
- 列表每批 30 张，使用小缩略图；详情、下载和输出使用原尺寸无损 WebP。大图支持缩放、1:1，保留横图与不同原始尺寸。
- 左右方向键/左右滑动详情图切换结果，`/` 搜索，`Esc` 关闭。
- 在图库选择中文/English 并点击“使用这张脸模”，素材 ID 和语言一起保存。取消不写回；图片加载失败保留旧选择。
- 正向、反向提示词及 ID 均可复制。提示词是离线库根据公开信息整理，不是原作者的生成提示词。

## 输出

| 输出 | 内容 |
|---|---|
| 🖼️脸模参考图 | 原尺寸 RGB IMAGE，float32、0–1，批次为 1 |
| 📝脸模说明 | ID、素材类型、发型与中文标签 |
| ✨脸模提示词 | 当前所选语言的正向提示词 |
| 🚫反向提示词 | 当前所选语言的反向提示词 |
| 🆔脸模ID | 原库稳定编号 |

示例：`example_workflows/美女脸模素材_预览.json`，仅连接 PreviewImage，不调用生成模型。

## 可移植性与素材

运行代码使用插件自身位置定位 `resources/face-gallery`，没有硬编码桌面路径、盘符、IP 或端口，也不会连接开发者的电脑。浏览器请求发送给使用者当前的 ComfyUI 服务。

```text
resources/face-gallery/
  manifest.json
  image/<ID>.webp
  thumb/<ID>.webp
  SOURCE-LICENSE.txt
  SOURCE-README.md
  verification.json
```

分发完整离线版本时必须连同此目录一起交付；只发布代码而不附素材，接收者会看到缺少目录的提示，不会偷偷请求某台电脑或自动下载。可以在拥有离线源库的电脑上运行 `python tools/prepare_face_gallery.py 源库目录 目标素材目录` 准备素材。脚本不修改源文件，已存在的目标图片会校验而不覆盖。

压缩为原尺寸、真正无损 WebP，不缩图、不降色、不磨皮；每张与源 PNG 逐像素比较。具体全量数据记录在 `resources/face-gallery/verification.json`。

来源：[AI モデル顔データベース](https://ai-portrait-gallery.pages.dev/)，作者あぎ（X: @agi_aibusi）。2026-10-29 核对页面标注 **CC0 1.0**，同时写有“请尽量不要直接再分发图片”的请求；此处保留这两项原站表述，不将请求写成服装库那种明确禁止再分发条款，也不提供额外授权保证。图片为 AI 生成的虚构人物，原站要求不要用于冒充真实人物等用途。

节点不依据外貌推断人物身份、年龄等属性；“美女脸模素材”为用户指定的显示名称，素材分类沿用离线库数据。
