# 无限模特孵化器

更新：2026-10-30。

节点：`DapaoModelIncubator`，显示名：`✨ 无限模特孵化器@炮老师小课堂`。
分类：`🍭大炮-llama-cpp`。

## 使用

1. 在 ComfyUI 搜索“无限模特孵化器”并添加。
2. 点“🎲 随机组合”，或分别打开脸模、服装、姿势图库手动选择。
   每张素材卡片右上角也有独立小骰子：只随机该项、排除当前素材，另外两项及提示词种子保持不变，并更新该图片接口直接连接的预览。上传模式下小骰子禁用，切回素材库可用。
3. 每个位置可独立切换为“上传图片”；支持 PNG、JPEG、WebP，前端限制 30MB。图片通过当前 ComfyUI 的原生 `/upload/image` 接口保存，不发送外部生图服务。重名交由原生上传接口处理，传入 `overwrite=false`。
4. 固定输出：图片1脸模、图片2服装、图片3姿势、整合提示词。三个图片接口保留各自原尺寸，并非拼图或相同尺寸的图像批次。
5. 连接支持多参考图的生成节点，并按这个顺序连接三张图片和提示词。需要生成成片时由用户手动运行工作流。

随机只替换来源为“素材库”的位置，保留上传图片。全上传时骰子只变换提示词模板。姿势库白名单为三个明确单人分类，共1164张；双人分类275张不出现在新节点随机池或手动选择中，后端同样拒绝双人ID。上传图不做人物数量识别，请用户自行提供单人姿势。

提示词通过后端本地模板统一生成，前端即时提示与执行输出共用函数。固定三图身份、服装、姿态职责，按保存的种子组合三种灯光和三种中性背景，共9种表达；不调用大语言模型，不描述或猜测自传图片的内容。

## 即时预览

- 三张素材齐全、完全无下游连线时，随机、手选、上传或“更新下游预览”会自动补三个独立 `PreviewImage`，并避让已有节点。
- 已有任何下游连线时尊重现有布局，不额外补预览。仅文字连线也不补图。
- 更新各图片输出直接连接的 `PreviewImage`。文字输出支持直接连接的 `PreviewAny`、`ShowText|pysssss`、`easy showAnything`；其他节点提示需要手动运行。
- 不追踪 Reroute、子图或中间图像处理节点；不提交 `/prompt`。
- 前端即时图不属于后端执行缓存。保存重开后可点“更新下游预览”；正常执行结果会接管即时图。
- 选项、图库 ID、上传文件名、提示词种子通过原生 widgets 序列化，紧凑界面隐藏了这些内部字段。
