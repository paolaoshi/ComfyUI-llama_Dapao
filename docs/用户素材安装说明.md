# 用户素材包安装说明

本说明对应 `ComfyUI-llama_Dapao` 插件。GitHub 提供代码，素材包单独提供。
素材包制作日期：2026-11-02。包内 `素材文件清单.json` 记录实际文件数、大小及 SHA-256。

## 给接收素材包的用户

1. 先安装或更新 `ComfyUI-llama_Dapao` 插件代码。
2. 找到你正在使用的那套 ComfyUI，进入以下插件目录：

   `ComfyUI/custom_nodes/ComfyUI-llama_Dapao/`

   不同整合包的盘符和外层文件夹可以不同，以你实际启动的 ComfyUI 为准。
3. 打开本素材包内的 `安装到插件目录` 文件夹，将其中的 **resources** 和 **web** 两个文件夹复制到上面的插件目录，合并同名文件夹。请勿替换或删除整个插件目录。若已有自己修改的同名素材，先备份，再决定是否覆盖。
4. 完成后的目录应如下。不要把“用户素材包”或“安装到插件目录”这层文件夹一起套在插件里面：

```text
ComfyUI/
└─ custom_nodes/
   └─ ComfyUI-llama_Dapao/
      ├─ __init__.py
      ├─ resources/
      │  ├─ face-gallery/
      │  │  ├─ manifest.json
      │  │  ├─ image/
      │  │  └─ thumb/
      │  ├─ costume-gallery/
      │  │  ├─ manifest.json
      │  │  ├─ image/
      │  │  └─ thumb/
      │  └─ pose-gallery/
      │     ├─ manifest.json
      │     └─ images/
      └─ web/
         └─ js/
            └─ comic_previews/
```

5. 如果 ComfyUI 正在运行，先保存工作流，再使用你平时的启动器正常重启这一套 ComfyUI，然后在浏览器按 **Ctrl+F5** 强制刷新。
6. 添加“美女脸模素材”“精选服装参考”“精选姿势参考”或“无限模特孵化器”，打开图库检查缩略图。选图后可连接“预览图像”检查图片输出。漫画创作选项的配图由 `web/js/comic_previews` 提供。

这些节点按插件自身所在目录读取素材，无需填写盘符、修改代码或配置模型路径。仅有素材包不能代替插件代码；安装素材本身也不会生成图片或运行工作流。

## 如果没有读到素材

- 先确认复制到了正在运行的那套 ComfyUI，尤其注意电脑上存在多个整合包的情况。
- 检查 `resources/face-gallery/manifest.json` 等文件是否就在上图的位置；不能多套一层文件夹。
- 原图、缩略图和 `manifest.json` 必须配套，不能只复制图片或改动图片文件名。
- 若图库正常但漫画选项无配图，检查 `web/js/comic_previews/`，再强制刷新网页。
- 如个别文件损坏或遗漏，按素材清单重新复制相应文件。

## 给制作与交付素材包的人

项目根目录下的 `用户素材包/` 是本地交付副本，包含说明、文件清单以及 `安装到插件目录/`。在确认素材可向接收者提供之后，可将整个文件夹交给对方。无需让用户从开发目录中逐个寻找素材。

包内不包含模型权重、账户配置、用户上传图片或运行截图。原来的 `resources/` 和 `web/js/comic_previews/` 仍供本机使用；交付包是独立复制的文件，不是快捷方式或依赖原目录的链接。

**来源与分发限制必须保留：**

- 脸模库自带说明记录 CC0，同时保留作者尽量不直接再分发图片的请求。
- 服装库自带说明明确禁止图片原件及加工版本再分发、转载或转售。未取得相应许可时，不应把该部分直接发给用户。
- 姿势库自带说明指出图片不属于代码的 MIT 许可，并注明不得商用。

以上是本地素材附带说明的摘要，不代表重新核验后的最新授权。详情见每个素材目录中的 `SOURCE-LICENSE.txt` 及其他来源说明；不能把本文件当作再分发许可。

`用户素材包/` 和各运行素材目录已被 Git 忽略。“提交 Git”默认仅提交代码及说明并推送云端，不包含本包。
