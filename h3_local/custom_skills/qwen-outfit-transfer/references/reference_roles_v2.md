# 静态换装参考职责协议 v2
只有需求以 EDIT_PLAN_V2、WARDROBE_ONLY_V2、POSE_GEOMETRY_V2 开头时才使用本协议，并取代 SKILL.md 中普通换装和旧姿势任务的输出规则。其他任务保持原行为。

## EDIT_PLAN_V2：仅根据人物原图制定改动清单
只收到人物原图，不包含服装图或姿势图。此任务不是写穿搭、视频、背景迁移或风格化建议。逐项分清人物身份、穿搭、动作、手持物、环境、光照、画幅的来源。用户提到哪项只改哪项，其他项保持；未提及不等于允许修改。
先观察实际人物原图的环境、前景、光源方向、软硬、时间感、肤色受光、白平衡和取景。用具体可见事实写保留要求，不能猜天气地点。再读用户原文，只为明确提出的属性制订变化；例如持物或动作改变只许可相应肢体与接触关系，不许可换场景、改全局色调或拉远画面。换衣颜色只变染料，不变光源或肤色；明亮服装不等于过曝全图。明确换背景时才改变场景，新环境须与人物受光合理协调；明确改光线、季节或氛围时才改变对应属性。用户说自拍并不要求变成室内镜面场景。
输出第一行 LOCAL 或 GLOBAL：动作、持物、背景或全局光变化需要 GLOBAL，但这仅是重绘范围，不代表全图内容均可变；只改衣料属性则 LOCAL。
接着仅输出 <plan> 包住一段英文指令，内容包含：
Scene: 人物原图的可见场景锚点与 KEEP 或用户明确的新环境。
Light: KEEP 原图白平衡/光照及具体方向与色温，或用户明确的变化。服装染料不等于全局滤镜。
Action: 用户要求的动作与物体接触，未要求则保留原道具，身体姿势交给启用的姿势分支；姿势分支关闭才保留原姿态；明确更换道具时撤除旧道具，确定哪只手怎么握、朝向、遮挡和支撑。可合理补足完成指定动作必要的接触，不能任意增加道具。姿势参考另行提供几何变化；不得锁死原图的伸臂、头倾、表情等未明确要求的几何细节。
Frame: 默认保留人物画幅和镜头位置，不为展示服装扩出手脚，用户明确要求新取景时才改变。
不要描述目标服装，因为没有给你看服装图。不要附分析、可选方案或无关背景建议。无需问用户。

## WARDROBE_ONLY_V2：只编译穿戴物
图1为人物，图2为已选服装，后续图仅为同款细节；附带的 SOURCE EDIT PLAN 来自独立读取人物原图，不受服装参考影响。
只输出 <edit>英文服装编辑指令</edit>，包含所选的衣料、结构、染料、印花、配件和适用部位。禁止输出任何背景、场景、天气、调色、曝光、光线风格、镜头、人物动作或道具更换指令——这些由 SOURCE EDIT PLAN 负责，不能重写。
真人穿搭参考只提供选中的穿戴物。模特的身份、发型、肤色、姿势、布景和摄影色调全部不迁移。冷暖灯光不要解释成衣物固有颜色；保持可辨认的面料颜色，同时交给人物现场光重照明。依照现有主体可见范围适配，不为展示鞋子补出画外的腿。
命名某件衣服的颜色仅修改该件属性，不缩小面板选中的完整搭配范围，除非用户明确只换某件。
保持原有细节归属、手绘范围、人台露肤与服装层次规则；独立配件不能漏掉，证据不足不编造。
只写服装，不写“保持原姿势”之类会与用户动作冲突的话。参考人物的手持物不是服装。选中物完全无可用部位且无其他用户要求时仅 KEEP_ORIGINAL_FRAME；有用户动作等要求时写 Keep the current clothing on non-applicable body regions，并让其他编辑继续。
交付前自检：每个颜色词都必须修饰具体服装或配件，不能修饰背景；每个动作词只能描述穿戴贴合，不能改变人姿势。删除违反来源职责的句子。总长度不超过 1500 英文字符。

## POSE_GEOMETRY_V2：只提取与适配动作
本任务图1是姿势参考，图2是人物原图（只作身份、取景和环境锚点），图3为结构控制图。没有给你看最终换装衣物，绝对禁止猜测或描述应保留的衣服。
仅用图1和图3推导身体朝向、重心、关节关系、手的位置、可见肢体、前后遮挡与支撑接触；不迁移其人物、衣料、头发、背景、沙发或地板。不要输出任何服装名称、颜色、丝袜或鞋履描述。手套等属于服装，不能根据姿势图重写。
根据人物原图场景适配支撑：参考坐姿依赖座面时，优先使用目标场景现有的座面或地面，必要时最少量补充合理的中性支撑，不复制参考室内整套家具。深度的灰度仅表示距离，不是色调；背景和家具深度不能主导成图环境。
用户明确指定的动作和持物优先于姿势参考中冲突的手势或道具。手握杯、花束、书、工具等均按物体形状、重力和手指接触适配，不固定为手机。未要求新物体时保留人物原有物体，参考里的道具只用于理解动作，不自动迁移。物体被身体遮住或出画时保持合理可见性。
只输出一段英文的可执行动作与接触指令，不写环境和服装，且不使用图号。姿势图无法判定有效人体时仅输出 POSE_SKIP。交付前删除所有不是动作、接触或遮挡关系的描述。
