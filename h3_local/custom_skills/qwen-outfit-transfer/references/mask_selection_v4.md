# 粗遮罩与穿搭选择协议 v4

用于 WARDROBE_INVENTORY_V4 和 WARDROBE_ONLY_V4。继承 visibility_layers_v3.md 的信息来源、实际入镜、人体几何、证据可信度规则；本文件替代其中“净图里所有可辨认物件都选中”以及宽泛保留原穿搭的规则。



## 选择意图不是逐像素复制

用户粗涂表示物件意图。结合原图、绿色叠加图和抠图判断每件物品：主要区域有涂抹、只有边缘擦过、明确留白、不可确定。绿色只是诊断标记，不是衣服颜色；原图提供真实色材质。

不能只按涂抹面积占整幅图的大小判断。小配件虽然小，主要本体被覆盖仍是选中；大衣只有一小条领边/侧边被擦到，主要衣身和袖子都没涂则属于边缘误碰，不补成整件。不要因边缘露出一点就推测用户想要整套。

涂抹围着外层的两侧和袖子、中间内搭明显留白，表示选外层、排除内搭；反过来中间衣身大面积涂抹、两侧外层基本留白，表示选内层。依服装的实体连接关系判定，不因同色或同属于一个身体区域就把独立层合并。补足已选部件少量漏涂边缘，但不能跨越明显留白去补另一件。

参考遮罩决定拿什么；人物遮罩决定允许改哪里。人物留白区不是新衣参考，不得从参考内搭替换它。仅有参考遮罩时，同样保留未选择的目标独立层。双侧遮罩时同时遵守两边意图。

没有有效手绘标记时，完整模式选整套有证据的穿戴物；高级按类别范围选择。不能把“保留原图”误扩展成保留已被选中替换的上衣、下装或配件。



## WARDROBE_INVENTORY_V4

运行时 NO_MANUAL_MASK 是确定的遮罩状态：True 表示没有有效手绘，选取候选净图中的完整物件清单，不能因没绿色而排除所有物件；False 才依据粗涂覆盖判断。该标志优先于模型对标记有无的猜测。

三图分别是完整原服装图、同图绿色遮罩叠加、当前候选净图。原图判断整件结构；叠加图判断选取意图；净图仅辅助定位，不作为扩大选择的授权。若没有绿色标记，按候选净图提供的范围；净图与原图相同则视为完整范围。

按物件逐个考虑外层、内层、下装/连体、头颈、手臂/手、腰腿、足部配件，确认是否主要选中。清单不得按目标人物裁切删除：它应保留已选整件的完整信息，供各阶段分别匹配可见部位。

先输出 <coverage> 每件独立物品自身表面：broad green / trace edge / no green；无手绘时写 no manual paint。必须逐件检查图2实际绿色，不能把图1存在的物品当成已涂。存在手绘时，自身没有绿色的独立物品不得列入 selected。 </coverage> 再输出两个简短区块：<selected>逐件写确认选中的物件、类型、真实颜色、显著结构和实际佩戴区段；标明主要涂抹证据（无手绘则完整候选）。</selected><excluded>只写因边缘误碰或明确留白排除的物件与原因；没有则 none。</excluded>。不得根据参考人体/人台猜出另一件内搭。人台颜色不是袜料；反之有清楚袜口/织纹/透明布料证据就应作为服装记录。保持350英文词以内。



## WARDROBE_ONLY_V4

图1目标人物、图2候选衣物；最后两图分别为完整服装的绿色选区图、目标人物的绿色选区图；三张可选特写由独立细节观察节点看图，并通过 DETAIL OBSERVATIONS 提供同款证据、位置与数量；本任务不重复读取三张特写。绿色图仅用于选择，不迁移其色彩。

保留的优先级：身份/比例/场景；用户明确保留区；未选中的独立穿戴物。已选且有可见落点的物件必须替换相应旧物。只选外层时写出人物原内搭/下装真实可见特征并保留，不能用参考里另一件没选中的内搭替换。只选内层时不引入边缘误碰的外层。若两边有遮罩，只描述目标允许区内的新衣与遮挡关系，不指令修改留白区。

继承 V3 的空交集 KEEP_ORIGINAL_FRAME 机制，否则仅输出 <edit>一个简短英文段落</edit>，优先完整覆盖每个适用部件，避免重复环境/光线/动作命令。不要在最终段落列出被排除的参考物，直接描述应保留的目标原件。对真正可见的款式以图像证据为准，不能把短裤改成长裙、把围巾改成衣领等。



## 4.1 衣长、构造与替换关系不可被裁切改写
衣物的物理终点和当前画面可见终点是两个不同事实。先依据整件参考确认原有衣长、开合、连续布片与独立袖管/裤管，再将可见区段投影到目标画面。画框经过大腿不等于新衣下摆在大腿；如果原下摆应在画外，只描述连续衣料从下沿离开，不能在画内另造短下摆、开衩或喇叭边。坐姿和跪姿改变褶皱及遮挡，不授权把连片衣料分成两条裤管，也不授权把长件改成短件。无需强行展示原本不在画内的设计终点。
选中的配饰替换目标上对应旧物及其相连的背带、提手和挂件，动作接触随新物适配。物件被手抓着或碰到地面不使它自动成为必须保留的场景。未选中、明确保留或没有可信替代物时才沿用旧物。功能道具如相机与服饰配件分开判断。此规则用于任意类别和携带方式，不能同时要求新增一件又保留被替换的同位旧件。
最终指令只负责服装、配饰及其必要接触，不重写场景和人物动作。画外物件彻底省略，不用否定句再次点名。
